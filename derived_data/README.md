# Derived Data

This directory contains machine-readable analysis outputs derived from the publicly available datasets used in:

## A Systems Biology Framework Links Gut Microbiome Metabolites to Regorafenib-Associated Transcriptional Programs in Colorectal Cancer

These files are provided to support reproducibility of the manuscript analyses and to make the principal derived results available without requiring regeneration of all intermediate analysis objects.

## Files

### `regorafenib_metabolite_concordance_scores.csv`

Regorafenib-metabolite transcriptional concordance scores generated by comparing metabolite-associated host gene-expression signatures with the LINCS regorafenib transcriptional perturbation profile.

The correlation coefficient represents genome-wide transcriptional concordance between each metabolite-associated gene signature and the regorafenib perturbation signature. Positive values indicate concordant transcriptional patterns, whereas negative values indicate opposing patterns.

---

### `prioritised_metabolites_regorafenib-concordant.csv`
### `prioritised_metabolites_regorafenib-opposing.csv`

Metabolites prioritized for downstream analysis based on statistical significance, transcriptional concordance magnitude, and consistency across the unadjusted, sex-adjusted, and disease-adjusted analyses.

This file includes both regorafenib-concordant and regorafenib-opposing candidates used in downstream pathway analyses.

---

### `pathway_enrichment_results_regorafenib-concordant.csv`

Complete FGSEA results for prioritized regorafenib-concordant metabolites.

Pathway enrichment was performed using KEGG gene sets. Reported statistics include normalized enrichment scores (NES), nominal p-values, and Benjamini-Hochberg-adjusted p-values.

---

### `pathway_enrichment_results_regorafenib-opposing.csv`

Complete FGSEA results for prioritized regorafenib-opposing metabolites.

Pathway enrichment was performed using KEGG gene sets. Reported statistics include normalized enrichment scores (NES), nominal p-values, and Benjamini-Hochberg-adjusted p-values.

---

### `longitudinal_sensitivity_scores.csv`

Results from the sensitivity analysis comparing regorafenib-metabolite transcriptional concordance scores derived using baseline stool metabolite measurements with scores derived using longitudinal metabolite profiles.

Longitudinal metabolite profiles were generated using repeated stool measurements while holding the baseline rectal transcriptomic profile fixed.

The file includes baseline and longitudinal concordance scores and metabolite rankings.

---

### `survival_analysis_results.csv`

Results from exploratory CRC survival analyses of genes associated with prioritized regorafenib-concordant and regorafenib-opposing metabolites.

The file contains Kaplan-Meier and/or Cox proportional hazards analysis outputs used to evaluate associations with overall survival in TCGA COADREAD.

---

### `cell_viability_results.xlsx`

Processed results from experimental evaluation of prioritized metabolites in HT-29 colorectal cancer cells.

The workbook contains dose-response measurements and summary statistics from the viability experiments, including the analyses reported in the manuscript.

Four technical replicate wells were assayed per concentration on the final experimental plate for each compound included in the quantitative analysis.

## Notes

These files represent derived analysis outputs rather than raw data.

Primary source datasets are publicly available from IBDMDB, LINCS / SigCom LINCS, and TCGA COADREAD / LinkedOmics, as described in the manuscript.

Large intermediate gene-metabolite correlation matrices are not included because of their file size. They can be regenerated from the source datasets using the analysis scripts provided in the repository.
