This folder contains supplementary figures associated with the manuscript:

# A Systems Biology Framework Links Gut Microbiome Metabolites to Regorafenib-Associated Transcriptional Programs in Colorectal Cancer

# Supplementary Figures

## Supplementary Figure S1a

**File:** `Figure S1a - Baseline versus longitudinal regorafenib transcriptional concordance scores.pdf`

**Title:** Baseline versus longitudinal regorafenib transcriptional concordance scores.

**Caption:** Each point represents one metabolite feature. Highlighted points indicate features corresponding to metabolites selected for experimental testing. Baseline regorafenib transcriptional concordance scores were compared with scores calculated using longitudinal metabolite profiles while holding baseline rectal gene expression fixed. Spearman rank correlation across 652 metabolites was ρ = 0.54.

## Supplementary Figure S1b

**File:** `Figure S1b - Regorafenib transcriptional concordance scores for experimentally tested metabolites.pdf`

**Title:** Regorafenib transcriptional concordance scores for experimentally tested metabolites across baseline and longitudinal metabolite profiles.

**Caption:** Heatmap shows Spearman correlation-based regorafenib transcriptional concordance scores for seven IBDMDB metabolite features corresponding to six experimentally tested metabolites; inosine was represented by two separate metabolite features. Positive values indicate regorafenib-concordant transcriptional patterns, whereas negative values indicate regorafenib-opposing patterns. All experimentally tested metabolite features retained positive concordance in both analyses.
